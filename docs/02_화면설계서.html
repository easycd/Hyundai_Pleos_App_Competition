다음에 가게 — 화면 설계서

작성일 2026-11-09 · 작성자 재원 (easycd) · 기준 문서: 01_개발기획서의 기능 ID(F-xx)를 그대로 쓴다.

주행 중에 쓰는 화면은 말하기 버튼과 큰 카드 몇 장으로 끝내고, 목록·편집·지도는 정차 중에만 연다. 화면 12개, 흐름 2개(주행 중·정차 중)다.

3. 화면 흐름

위 줄은 주행 중 음성으로 도는 흐름, 아래 줄은 정차 중 터치 화면이다. 정차 화면을 주행 중에 열면 S-12가 대신 뜬다. 내비 안내는 Pleos 내비 앱으로 넘어가는 바깥 화면이다.

7. 확인이 필요한 사항

  • 캔버스 1280×1080은 가정이다. 에뮬레이터 실제 해상도를 확인하면 비율만 다시 맞춘다.
  • S-07 지도는 카카오맵 SDK가 차량에서 뜨는지에 달려 있다. 안 뜨면 프로토타입은 목록만 쓰고 지도 자리는 비워 둔다.
  • S-05 리마인드를 앱 밖(내비 화면 위)에 띄우려면 차량 알림 권한이 필요하다. 안 되면 앱이 켜져 있을 때만 띄운다.
  • 스티어링 휠 음성 버튼 연동은 Pleos SDK에 없어 말하기 버튼은 화면에만 둔다.
