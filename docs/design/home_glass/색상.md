## 유리(Liquid Glass) 규칙

- 컨트롤 층(상단 알약 바·버튼·카드)만 유리. 콘텐츠 층(배경·지도)은 유리 금지 (Apple HIG 머티리얼).
- 유리 = 흰색 8%(다크)/55%(라이트) + backdrop blur 28px saturate 170% + 테두리 1px 흰 22%/90% + 위쪽 안쪽 흰 선 1px + 왼쪽 위에서 오는 연한 하이라이트 그라데이션.
- 색을 입힌 유리는 1순위 동작(말하기 버튼) 1개만. 나머지 유리는 색 없이 뒤 배경색을 비침 (HIG 색: 여러 컨트롤 배경에 색 금지).
- 모서리: 알약(999) 또는 36dp. 그림자 0 24 60 (다크 검정 45%, 라이트 갈색 18%).
- 동작 줄이기·투명도 줄이기 설정이면 blur 없이 불투명 카드색(다크 #1F1714, 라이트 #FFFFFF)으로 대체.
