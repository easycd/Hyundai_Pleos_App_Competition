# Apple 디자인 가이드(HIG) 확인 결과 — 다음에 가게 적용 점검

확인일 2026-11-09 · 확인 범위: https://developer.apple.com/kr/design/ 의 Human Interface Guidelines 전체(아래 1장) · 비교 대상: [02_화면설계서](../02_화면설계서.md) 커밋 e249833, [앱 아이콘 최종](../design/icons/final/)

## 0. 요약

- Apple HIG는 iOS·CarPlay 등 Apple 플랫폼 기준이다. 우리 앱은 Pleos Connect(안드로이드 기반 차량 OS) 앱이므로 **Apple 전용 기술(Liquid Glass, SF Symbols, Dynamic Type API 등)은 원칙만 가져오고**, 수치는 CarPlay 장을 참고했다.
- 점검 결과: **적용됨 약 30 · 수정 제안 16 · 결정 필요 3 · 해당 없음 다수**. 수정 제안은 4장에 번호를 붙여 두었으니 번호로 골라 주면 화면 설계서에 반영한다.
- 가장 크게 어긋나는 것 3가지: ① 시작 화면(S-00)에 아이콘 스플래시를 두는 것(HIG는 금지) ② 처음 실행 안내(S-13)에 "나중에" 버튼을 두는 것(권한 사전 안내 화면은 버튼 1개만) ③ 강조색(파랑)이 앱 아이콘 색(주황)과 다르고, 파랑을 "누르는 것"과 "상태(선택 칩)" 양쪽에 쓰는 것.

## 2. 디자인 원칙 8개와 우리 앱

| 원칙 | Apple의 말 | 우리 앱 점검 |
| --- | --- | --- |

## 3. 영역별 핵심 규칙과 우리 설계서 상태

판정: **적용됨** = 이미 맞음 · **수정 제안** = 4장 번호 참고 · **결정 필요** = 재원이 골라야 함 · **참고** = 구현 단계(기술서)에서 반영
